# 结果、风险与局限

## 可核验结果

| 项目 | 结果 |
|---|---:|
| 早期公开基线 | 约 0.00301924 |
| 15-member 可复现版本 | 0.0039380 |
| 最终公开最好成绩 | 0.00394663 |
| 公开榜位置 | 第 23，67 次提交 |
| 最终隐藏时段成绩 | 0.00301583 |
| 最终隐藏榜位置 | 第 37 |

从早期公开结果到最终公开最好成绩，相对提升约 `30.7%`。但原始分数受任务定义、样本权重和市场阶段影响，不适合脱离上下文作为简历主叙事；更有价值的是系统规模、方法演化、可复现性和对泛化风险的认识。

## 本地增量

可复现 15-member 模型相对 8-member E3：

| 指标 | Fold 7 | Fold 8 |
|---|---:|---:|
| E3 | 0.00218783 | 0.00219558 |
| 15-member | 0.00233118 | 0.00245256 |
| 增量 | +0.00014334 | +0.00025698 |

这部分提升来自成员集合与 stack，不依赖最终公开分数反馈，因而是最可信的研究结果。

## 公私榜差异

公开最好到最终隐藏时段绝对下降约 `0.0009308`。已有证据支持以下共同原因：

1. **时间分布漂移**：训练 fold 与公开测试已高度可分，隐藏时段进一步变化；
2. **公开反馈适配**：输出标准差与 level 分量经过公开反馈确认，天然更贴合公开 regime；
3. **验证代表性不足**：Fold 8 无法完整模拟更远未来；
4. **制品保真差异**：完整 15-member 的全部在线 booster 没有在最终阶段完整保存，私榜使用经 A/B 选择的简化 fallback；
5. **弱信号放大风险**：指标绝对值很小，微小 regime 变化即可改变模型排序。

因此，项目成果不能被表述为“最终排名 23”。正确说法是：公开榜最好第 23，最终隐藏榜第 37；研究上取得显著公开提升，但未来泛化不足。

## 被证伪的方向

- 单纯提高 weight predictor R²；
- 使用预测 target 递归替代训练期真实历史 target；
- residual MLP/FT-Transformer/GRU/TCN 的激进融合；
- XGBoost、CatBoost、ExtraTrees 作为弱而低相关成员；
- 基于高置信度、tail、asset 或 regime 的公开后处理；
- 利用跨资产 lead-lag、图卷积或 panel attention；
- 从可见特征预测逐行 intervention utility；
- 用未来测试特征或完整测试分布做当前预测，这不仅风险高，而且违反严格时序规则。

## 如果重新做一次

1. 从第一天开始保存每个生产 booster、OOF 行键和 exact environment；
2. 使用更多滚动窗口的 outer walk-forward，并优化最坏 fold 而非平均 fold；
3. 把公开榜提交预算预先分配，只做少量机制确认；
4. 在训练时就构建与最终 sequential API 完全一致的在线特征状态；
5. 让最终模型选择同时考虑分数、跨 fold 方差、复杂度和 deploy fidelity；
6. 更早建立成员残差相关性门，减少在已被 stack 吸收的方向上消耗算力。
